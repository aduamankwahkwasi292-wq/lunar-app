# MrSOLIS 3 — the website

The page at https://aduamankwahkwasi292-wq.github.io/lunar-app/ (GitHub Pages, from this repo's `main` branch).

MrSOLIS 3 is an offline study tutor for Windows by Behemoth Group: lessons from your own slides, quizzes it marks,
exact maths with CUSTOM-Mx and CUSTOM-SQE, and voice. The installer is on the
[MrSOLIS releases](https://github.com/aduamankwahkwasi292-wq/lunar/releases/latest); the Download buttons find it there.

Plain HTML, CSS and a little JavaScript, no build step. The screenshots are of the real app, made with the tools
beside the site's source on the owner's laptop (`Downloads\lunar\mrsolis-website-tools`).
